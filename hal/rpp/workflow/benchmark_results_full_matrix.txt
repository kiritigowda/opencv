RPP HAL comprehensive benchmark — 1920x1080, 100 iters, 5 warmups
Host: santiago (AMD Radeon RX 7900 XT GPU + Ryzen 9 7900X CPU), ROCm 7.14, RPP 3.1.2
OpenCV 5.1.0-dev. Date: 2026-07-15.
All numbers are ms/op (lower is better).

Configs:
  native   = OpenCV native AVX (OPENCV_RPP_DISABLE=1), via cv:: API
  hal-cpu  = RPP HOST backend through the HAL (OPENCV_RPP_FORCE_CPU=1), via cv:: API
  hal-hip  = RPP HIP  backend through the HAL (default), via cv:: API [includes H<->D copy]
  rpp-cpu  = direct rppt_* on HOST backend, no OpenCV, upload-once/download-once [pure kernel]
  rpp-hip  = direct rppt_* on HIP backend — NOT RELIABLY MEASURABLE standalone (see note)

NOTE on rpp-hip (direct): RPP 3.x HIP kernels enqueue on RPP's internal stream
asynchronously; a standalone harness cannot cleanly time them (hipDeviceSynchronize on
the default stream returns in ~0.5us before the kernel runs, and several kernels launch-
error and poison the context). The verified, correct GPU measurement is hal-hip, which
forces synchronization via its per-call H<->D copies and is proven correct by the test
suite. Direct rpp-cpu (HOST) IS valid and shown below.
